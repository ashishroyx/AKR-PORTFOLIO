**Respawn** is a game-inspired social web application designed for gamers, creators, and streamers to share, connect, and showcase their content.  
It combines modern design, smooth animations, and a player-first experience to deliver an interactive platform where gaming culture thrives.  

---

## What is Respawn?

Respawn is a **gaming content and community platform** where users can post updates, highlight games, and build a digital identity around their interests. Whether you are a creator, a casual player, or an engaged spectator, Respawn provides the tools to express and connect.  

### Core Capabilities
- Create and edit game-related posts with media support  
- Build a personalized gamer profile with avatar, bio, and preferences  
- Explore a modern, scrollable feed of posts from the community  
- Edit and delete posts with real-time updates  

---

## Tech Stack & Features

- **React.js** – modular frontend development  
- **Tailwind CSS** – utility-first styling and custom themes  
- **Appwrite** – backend-as-a-service for authentication, database, and storage  
- **Framer Motion** – animations and interactive transitions  
- **Lucide Icons** – minimal, scalable icons for UI clarity  
- **Protected Routes** – secure access for authenticated users  
- **Dynamic Feed** – live rendering of posts with Appwrite subscriptions  

---

## Design & UX Principles

Respawn is built to feel like a **gaming dashboard**—responsive, fast, and visually engaging. Every design choice reflects the energy of gaming culture while keeping usability front and center.  

- Card-based layout with hover states for interactivity  
- Fully responsive across desktop, tablet, and mobile  
- Motion-enhanced transitions for smooth navigation  
- Dark and light gamer-inspired themes  
- Accessible UI with clear calls-to-action  

---

## Development Highlights

- Integrated **Appwrite** for authentication, real-time database updates, and media storage  
- Implemented secure login flows with protected routes  
- Built modular components such as **PostCard**, **UserProfile**, and **EditModal**  
- Enabled real-time updates through Appwrite event listeners  
- Added image uploads and media management via Appwrite’s storage SDK  
- Prepared feed filtering and sorting logic for future feature expansion
