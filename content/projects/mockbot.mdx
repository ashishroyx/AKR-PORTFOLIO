**MockBot** is an interview preparation platform powered by AI, designed to help candidates practice smarter.  
It generates personalized interview questions based on the role you describe and provides detailed answers, making preparation structured and effective.  

---

## What is MockBot?

MockBot takes the guesswork out of interview preparation. Instead of searching for random question banks, users can describe the role they’re aiming for, and the platform instantly generates relevant questions along with clear, detailed answers. This creates a focused, role-specific preparation experience.  

### Core Capabilities
- Generate interview questions tailored to the user’s described role  
- Provide detailed, AI-powered answers for each question  
- Clean and professional interface for easy interaction  
- Store and manage question sets with a connected backend  

---

## Tech Stack & Features

- **React.js** – interactive frontend with modular components  
- **Gemini AI** – intelligent generation of role-specific questions and answers  
- **Shadcn UI** – accessible and modern UI components  
- **Tailwind CSS** – responsive and scalable design system  
- **Express.js** – backend API for request handling and integration  
- **MongoDB** – database for storing user data and generated sessions  

---

## Design & User Experience

The design emphasizes simplicity and focus, allowing users to concentrate on preparing without distraction.  

- Minimalist UI with a clean layout for questions and answers  
- Responsive design that works across desktop and mobile devices  
- Intuitive flow: describe role → get questions → review answers  
- Consistent typography and spacing for clarity and readability  

---

## Development Highlights

- Integrated **Gemini AI** to generate interview questions and detailed responses dynamically  
- Built a **role-based input system** that tailors preparation to user goals  
- Developed reusable components such as **QuestionCard**, **AnswerView**, and **RoleInputForm**  
- Connected to a **MongoDB database** to persist sessions and responses  
- Implemented a scalable backend with **Express.js** to handle AI queries and data storage
