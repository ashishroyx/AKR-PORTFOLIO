**Elden Ring Animated Landing Page** is a creative exploration into motion design and interactive storytelling on the web.  
The project reimagines a landing page experience inspired by the game *Elden Ring*, blending animation, parallax effects, and visual transitions to create a cinematic introduction.  

---

## What is the Elden Ring Landing Page?

This project is both a design and technical challenge aimed at experimenting with advanced animation techniques in a web environment.  
The goal was to move beyond static layouts and instead deliver an immersive, game-like landing page that responds to user interaction and sets a strong visual tone.  

### Core Capabilities
- Animated landing sequence with SVG masking and text reveals  
- Parallax motion effects responsive to cursor movement  
- Smooth transitions and timeline-based animations powered by GSAP  
- Character intro animation designed to simulate a dynamic entry sequence  

---

## Tech Stack & Features

- **React.js** – structured component-based development  
- **Tailwind CSS** – utility-first styling for responsive layouts  
- **GSAP (GreenSock)** – animation library for precise transitions and motion control  
- **SVG Masking** – cinematic text reveal effects and intro animations  
- **System Fonts + Remix Icon** – lightweight typography and icon system  
- **Custom Animations** – including a "self-intro" character animation on load  

---

## Design & Creative Direction

The focus of the landing page is to merge fantasy aesthetics with interactive storytelling. Motion is treated as a design element in itself, elevating the overall user experience.  

- Cinematic intro sequence using SVG masks and GSAP timelines  
- Parallax-driven cursor movement to add depth and immersion  
- Bold typography paired with subtle transitions for contrast  
- A layout designed to feel more like a narrative opening than a static webpage  

---

## Development Highlights

- Built fully animated sequences using GSAP timelines for consistent, smooth motion  
- Created reusable React components to manage complex animation states  
- Implemented SVG masking techniques for text reveals and dynamic intros  
- Developed parallax effects that respond interactively to user cursor movement  
- Designed a modular system so animations and content can be extended easily
